Про проєкт
Цей репозиторій — це мій невеличкий вебзастосунок для автоматичного аналізу українського тексту. Головна його задача — розбивати слова на склади за всіма правилами орфографічного переносу.
Я намагалася зробити так, щоб програма "розуміла" складні нюанси нашої мови (апострофи, м'які знаки) і при цьому не ламала коми чи крапки в реченнях. Як додаткове завдання, застосунок ще й визначає частину мови для кожного слова.
Демонстрація
Застосунок вже працює онлайн, його можна зручно поклацати прямо в браузері без жодних встановлень:  Відкрити мій застосунок на Streamlit https://ukr-hyphenator-htz8tsd8nyzy5jwpw23mne.streamlit.app/
Що вміє ця програма?
Правильні переноси: алгоритм ділить слова на склади, суворо дотримуючись правила "не відривати і не залишати одну літеру".
Дружить з апострофом: програма знає, що дефіс має стояти після апострофа (наприклад, Бур'-ян), а літери ь та й не відриваються від своїх складів.
Не губить пунктуацію: текст акуратно розбирається через регулярні вирази, тому всі коми, крапки та знаки питання залишаються на своїх законних місцях.
Морфологія: за допомогою NLP-бібліотеки pymorphy3 програма підказує, яка це частина мови (іменник, дієслово тощо).
Простий інтерфейс: все працює у зручному віконці, написаному на Streamlit.
Технології
Мова: Python 3.11+
Бібліотеки: pymorphy3, pymorphy3-dicts-uk, re
Інтерфейс та хостинг: Streamlit, Streamlit Community Cloud
Автотести: pytest
Як запустити код у себе на комп'ютері
Якщо ви захочете протестувати програму локально, ось коротка інструкція:
Завантажте проєкт до себе:
git clone https://github.com/Karina290907/ukr-hyphenator.git
Зайдіть у папку та встановіть потрібні бібліотеки:
cd ukr-hyphenator
pip install -r requirements.txt
Запустіть сам застосунок:
streamlit run app.py
Після цього сторінка автоматично відкриється у вашому браузері (зазвичай на localhost:8501).
Тестування
Щоб переконатися, що алгоритм не ламається на складних словах чи англійському тексті, я написала автоматичні тести. Запустити їх можна цією командою в терміналі:
pytest test_hyphenator.py
